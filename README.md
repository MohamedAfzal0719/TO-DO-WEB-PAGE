# TO-DO-LIST-WEB-PAGE
1. Introduction

This project is a simple To-Do List Web Application designed to help users manage daily tasks efficiently.
It is built using HTML, CSS, and JavaScript, featuring an interactive task manager where users can add, complete, and delete tasks.
The application provides a minimal, responsive, and user-friendly interface.

2. Objectives

Build a responsive and interactive task management web page

Allow users to add, mark as completed, and delete tasks

Provide a clean and simple interface with smooth user experience

Demonstrate the use of basic frontend technologies (HTML, CSS, JavaScript)

3. Methodology

Frontend: HTML for structure, CSS for styling, JavaScript for functionality

Design: Card-based container with modern UI and button styles

Process:

Input field and button for adding new tasks

Task list displayed dynamically

Checkbox for marking tasks as completed

Delete button for removing tasks

4. Features

📝 Add Tasks: Users can input and add new tasks easily

✅ Mark Completed: Checkbox allows tasks to be marked as done (with strikethrough effect)

❌ Delete Tasks: Remove tasks instantly with a delete button

🎨 UI/UX Design: Clean interface with hover effects and smooth interactions

⌨️ Keyboard Support: Pressing Enter key also adds tasks

5. Conclusion

The To-Do Web Page project demonstrates how web technologies can be used to create an interactive and practical task management tool.
It provides a simple yet effective platform for organizing tasks and learning JavaScript DOM manipulation, event handling, and UI design principles.
